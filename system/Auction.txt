Nhóm Auction (Đấu Giá):

-case "START_AUCTION":
    + Json nhận vào :{
                       "action": "START_AUCTION",
                       "itemId": "item123",
                       "durationMinutes": 60
                     }
    + Json trả về (Cho người tạo):{
                                    "action": "START_AUCTION_REPLY",
                                    "status": "SUCCESS",
                                    "auctionId": "auc789"
                                  }
    + Json Broadcast (Báo cho toàn server):{
                                             "action": "GLOBAL_NOTIFY",
                                             "message": "Món hàng mới lên sàn: Bức tranh mùa thu!"
                                           }
    + Tr hợp thất bại :{
                         "action": "ERROR",
                         "message": "Bạn không thể mang đồ của người khác đi đấu giá!"
                       }
    + Luồng chạy: ClientHandler ---> AuctionController ---> AuctionService ---> AuctionRepository ---> ClientHandler (và ClientManager để broadcast)

-case "SCHEDULE_AUCTION":
    + Json nhận vào :{
                       "action": "SCHEDULE_AUCTION",
                       "itemId": "item123",
                       "startTime": "2026-05-01T08:00:00",
                       "endTime": "2026-05-01T20:00:00"
                     }
    + Json trả về :{
                     "action": "SCHEDULE_AUCTION_REPLY",
                     "status": "SUCCESS",
                     "auctionId": "auc101"
                   }
    + Tr hợp thất bại :{
                         "action": "ERROR",
                         "message": "Lỗi định dạng thời gian. Vui lòng dùng chuẩn yyyy-MM-ddTHH:mm:ss"
                       }

-case "GET_AUCTIONS":
    + Json nhận vào :{
                       "action": "GET_AUCTIONS"
                     }
    + Json trả về :{
                     "action": "AUCTIONS_LIST",
                     "data": [
                         {
                             "id": "auc789",
                             "item": {...},
                             "currentPrice": 1500000,
                             "status": "RUNNING"
                         }
                     ]
                   }

-case "BID":
    + Json nhận vào :{
                       "action": "BID",
                       "itemId": "auc789", // Lưu ý: Code đang dùng tên biến là itemId nhưng truyền vào đấu giá
                       "amount": 2000000
                     }
    + Json trả về :{
                     "action": "BID_REPLY",
                     "status": "SUCCESS"
                   }

-case "GET_AUCTION_HISTORY":
    + Mô tả: Dùng để lấy toàn bộ lịch sử giá của 1 phiên đấu giá (để vẽ Line Chart lúc vừa mở màn hình lên).
    + Json nhận vào :{
                       "action": "GET_AUCTION_HISTORY",
                       "auctionId": "auc789"
                     }
    + Json trả về :{
                     "action": "AUCTION_HISTORY_REPLY",
                     "data": [
                         {
                             "timestamp": "2026-04-29T20:00:01",
                             "price": 1000000
                         },
                         {
                             "timestamp": "2026-04-29T20:05:30",
                             "price": 1200000
                         }
                     ]
                   }
    + Tr hợp thất bại :{
                         "action": "ERROR",
                         "message": "Không tìm thấy lịch sử cho phiên đấu giá này!"
                       }
    + Luồng chạy: ClientHandler ---> AuctionController ---> UserService (hoặc AuctionService) ---> Repository ---> ClientHandler

-case "REALTIME_BID_UPDATE":
    + Mô tả: Mọi Client không cần gửi gì lên. Cứ hễ có ai Bid thành công, Server sẽ chủ động BẮN LOA cái JSON này về. UI bắt được thì tự động vẽ thêm 1 điểm nối tiếp vào biểu đồ Line Chart.
    + Json Server chủ động bắn về (Broadcast): {
                                                 "action": "REALTIME_BID_UPDATE",
                                                 "auctionId": "auc789",
                                                 "newPrice": 1500000,
                                                 "timestamp": "2026-04-29T20:10:00"
                                               }
